# معماری

> ترجمهٔ فارسی [ARCHITECTURE.md](ARCHITECTURE.md). اگر دو متن با هم نخواندند، نسخهٔ انگلیسی مرجع است.

```
MCP client (Claude, Cursor, ...)
        │  stdio / streamable-http
┌───────▼────────┐
│ server.py      │
├────────────────┤
│ service.py     │
├────────────────┤
│ shape.py and   │
│ the pure       │
│ modules        │
├────────────────┤
│ clients.py  cli.py  resolver.py  api.py  client.py
│ dates.py  text.py  glossary.py
└────────────────┘
```

لایه‌ها از بالا به پایین:

- **`server.py`**: روی FastMCP یا MCPServer، ۳۸ ابزار فقط‌خواندنی، ۴ پرامپت و ۱ منبع (resource) ثبت می‌کند. خطاهای قابل‌انتظار به `ToolError` خوانا تبدیل می‌شوند.
- **`service.py`**: کلاس `Bourse`؛ برای هر ابزار یک coroutine. فراخوانی‌ها را هماهنگ می‌کند، منبع‌ها را به هم وصل می‌کند، ورودی را اعتبارسنجی می‌کند و پیش‌فرض‌ها را تعیین می‌کند (آخرین روز معاملاتی، بازهٔ جلسه).
- **`shape.py` و ماژول‌های خالص**: توابع **خالص** (بدون I/O) که پاسخ خام را به دیکشنریِ تمیز تبدیل می‌کنند. همهٔ محاسبات اینجاست.
  - `shape.py`: قیمت‌ها، صف‌ها، بازسازی عمق بازار، تجمیع تیک‌ها، تعدیل قیمت و جریان حقیقی/حقوقی.
  - `market.py`: ردیف‌های دیده‌بان بازارِ خودِ بورس و دسته‌بندی انواع نماد.
  - `screener.py`: زبان امنِ فیلتر که پشت `screen_stocks` است.
  - `derivatives.py`، `indices.py`، `funds.py`، `toplists.py`، `calendar_events.py` و `status.py`: اختیار و آتی، شاخص‌ها، صندوق‌ها، فهرست‌های برترِ رسمی بورس، تقویم افزایش سرمایه و وضعیت معاملاتی.
- **`clients.py`**: دستورالعمل نصب برای ۱۷ عامل هوشمند (متن تنظیمات، لینک‌های یک‌کلیکی، ادغام امن فایل پیکربندی).
- **`cli.py`**: `serve | doctor | tools | call | config | install`.
- **`resolver.py`**: نماد، نام یا `insCode` را به یک `Instrument` تبدیل می‌کند (با تطبیقِ یکسان‌سازی‌شده).
- **`api.py`**: برای هر endpoint بالادستی یک متد؛ پاسخ خام برمی‌گرداند و زمان ماندگاری کش (TTL) را تعیین می‌کند.
- **`client.py`**: پوشش روی httpx: User-Agent مرورگر، تلاش مجدد (برای 403 و 429 و 5xx)، دورهٔ سردشدن (cooldown) برای هر میزبان پس از 429، کش TTL+LRU و سقف ۶ درخواست هم‌زمان.
- **`dates.py`، `text.py`، `glossary.py`**: تاریخ و ساعت (تقویم تعطیلات رسمی هم در `dates.py` است)، یکسان‌سازی متن و واژه‌نامه.

اصول طراحی:

1. **هستهٔ خالص.** ماژول‌های تبدیل هیچ I/O ندارند، پس هر عدد را می‌شود بدون شبکه روی fixtureهای ضبط‌شده آزمود (`tests/fixtures` که با `scripts/capture_fixtures.py` ثبت می‌شوند). علاوه بر آن، **تست‌های قرارداد** (`tests/contract`) هر ابزار را از مسیر سرور MCP و روی پاسخ‌های واقعیِ ضبط‌شده (بازپخش با `respx`) صدا می‌زنند؛ نگاه کنید به [tests/README.md](../tests/README.md).
2. **واقعیت در برابر استنباط.** مقادیری که بورس منتشر می‌کند همان‌طور که هستند برگردانده می‌شوند (پس از اصلاح واحد و نام فیلد). هر چیز محاسبه‌شده با نام `*estimate*` یا `*estimated*` مشخص می‌شود یا در یادداشت همان فیلد توضیح داده می‌شود.
3. **صرفه‌جویی در توکن.** سری‌های بزرگ به‌طور پیش‌فرض خلاصه می‌شوند (`trade_summary` و نمونه‌های `order_book_history`). دسترسی خام هم هست، اما سقف دارد و قابل فیلتر است.
4. **با صدای بلند و مفید شکست بخور.** نماد ناشناخته؟ خطا نزدیک‌ترین گزینه‌ها را فهرست می‌کند. IP خارجی؟ خطا همین را می‌گوید و `IRAN_BOURSE_PROXY` را نام می‌برد. محدودیت نرخ (rate limit)؟ خطا همین را می‌گوید و اینکه تا چه مدت. endpoint برای این نماد کاربرد ندارد (مثلاً HTTP 500 وقتی سهم را به endpoint صندوق می‌دهیم)؟ پیام روشن «برای این ابزار موجود نیست»، نه stack trace.
5. **برای همیشه فقط‌خواندنی.** هیچ ابزاری سفارش ثبت، تغییر یا لغو نمی‌کند و هیچ‌کدام با اعتبارنامه (credential) کار ندارد.
6. **هر دو نسل MCP SDK.** `server.py` یا `MCPServer` (SDK نسخهٔ ۲) یا `FastMCP` (نسخهٔ ۱) را import می‌کند؛ CI هر دو را آزمون می‌کند.
7. **هرگز `eval` نه.** اسکرینر فیلتر را با `ast` پایتون تحلیل می‌کند، با فهرست مجاز می‌سنجد و به closure تبدیل می‌کند؛ نمی‌تواند چیزی import یا صدا بزند و اندازه و عمق فیلتر محدود است.

افزودن یک ابزار: endpoint را به `api.py` اضافه کنید، تبدیل را به یک ماژول خالص (همراه تست)، هماهنگی را به `service.py`، ثبت ابزار را (با docstring غنی، چون همان چیزی است که مدل می‌بیند) به `server.py`، یک سناریوی قرارداد در `tests/contract` همراه ضبطِ آن، و بعد `scripts/gen_tools_doc.py` را اجرا کنید.
