The problem

An agent with a browser still cannot read this market.

We tested it. The market's data exists, but it is hidden behind JavaScript, written in codes, and shipped in megabytes.

The site is an empty shell

Fetching a symbol page from tsetmc.com returns a title and nothing else. Codal's report list comes back as unrendered template placeholders.

GET tsetmc.com/instInfo/4634…
→ ".:TSETMC:. :: مدیریت فناوری بورس تهران"
GET codal.ir/ReportList.aspx
→ {{::letter.Title}}  {{::letter.PublishDateTime}}

The hidden API speaks in codes

The JSON endpoints that hold the data use cryptic names and have traps. The exchange's own change field said zero for a stock that rose 120 rial.

"qTotTran5J": 646253701,
"pMeDem": 4210, "zOrdMeOf": 7,
"priceChange": 0.0,
"pClosing": 4210, "priceYesterday": 4090

One day of ticks is 3 MB

Order-book history is a delta feed that must be reassembled, shareholder rows come back twice, and a symbol's messages weigh 3.5 MB. None of it fits a context window.

Trade/GetTradeHistory   3.1 MB
BestLimits/{ins}/{day}  3.3 MB
Msg/GetMsgByInsCode     3.5 MB
GetClosingPriceDailyList 1.5 MB

New: stock screener

      
The filter box of tsetmc.com, written by your agent.

      
Say what you want in plain words. The agent writes a short condition and gets back only the stocks that pass it right now, with the evidence for each hit.

Today and 60 days back
Live values, yesterday (close[1]), averages (avg(volume, 20)), streaks (all(close_pct > 0, 3)) and highs over any window, adjusted for capital increases.

      
3,700 instruments, real money, order book
Shares, funds, bonds, options and futures from the exchange's own feed, with real vs legal flow, a five-level book, base volume and fund NAV.

      
Safe, and it explains itself
Conditions are parsed, never executed. Mistakes come back with suggestions, 15 presets are built in, and every hit shows the numbers behind it.

Install

      
Three steps. Any agent.

      
One server, every client that speaks MCP. Pick yours below, or use the shell command if your agent has no MCP support.

    

    

      
1 · Get uv
uv runs the server without a manual install.

        
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

        
curl -LsSf https://astral.sh/uv/install.sh | sh

      
2 · Check access
From a machine in Iran, confirm TSETMC and Codal answer.

        
uvx --from git+https://github.com/msmahdinejad/iran-bourse-mcp iran-bourse-mcp doctor

      
3 · Connect
Choose your agent. Some have a one-click link or an auto-installer.

How it works

      
One pure core, three public sources.

      
Transformation logic is separate from I/O, so every number can be tested offline against recorded real data. Facts are returned as published; derived numbers are labelled.
